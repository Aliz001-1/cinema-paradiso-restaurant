# Cinema Paradiso — React rebuild

Premium responsive React/Vite rebuild of the supplied Cinema Paradiso restaurant ordering website.

## Included
- Cinematic animated hero video with restaurant image fallback + Ken Burns motion
- Responsive glass/luxury navigation with mobile menu
- Heritage/story section and asymmetric image gallery
- Full interactive menu with all source items and category filtering
- Premium non-square food cards, hover states, ratings and badges
- Item detail modal: ingredients, sizes, quantity, cooking instructions
- Cart drawer with quantity controls, pickup/delivery mode, 9% tax and checkout success state
- Digital brochure modal
- Responsive reservation form
- Amsterdam map embed + directions link
- WhatsApp floating action + back-to-top
- Responsive footer, opening hours, contact and newsletter UI

## Run
```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.
